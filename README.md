# Bari Dental Clinic Website

A modern and responsive dental clinic website designed to make it easy for patients to explore dental services, find clinic information, and get in touch.

## Features

- Dental services and treatment information
- Appointment enquiry through WhatsApp
- Direct call and WhatsApp contact options
- Clinic location and directions
- FAQ section
- Responsive mobile navigation
- Mobile-friendly design
- Basic SEO optimization

## Built With

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- Vite
